# 🤲 Telegram Prayer Reminder Bot

Bot Telegram (Telethon) që dërgon automatikisht dhikër dhe lutje arabe çdo 10 minuta, me komandat /start dhe /stop. Demoja web simulon bisedën: shtyp Start dhe lutjet reale arabe nga kodi origjinal shfaqen automatikisht.

## 🚀 Si ta hapësh

Hap `index.html` në browser, kliko **Live Demo**, pastaj shtyp **▶ /start** — lutjet arabe shfaqen automatikisht çdo ~10 sekonda (të përshpejtuara për demo). **⏹ /stop** i ndalon.
